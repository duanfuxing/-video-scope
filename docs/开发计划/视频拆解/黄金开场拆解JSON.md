# 黄金开场拆解 JSON（讨论稿）

日期：2026-11-10。状态：结构讨论稿，尚未定稿、实现或入库；不是模型提示词、JSON Schema 或运行时契约。对应的[优质视频拆解格式](优质视频拆解JSON.md)描述整片参考。

## 1. 用途与边界

面向黄金开场，兼顾“开场参考”和“开场换元素复刻”：精拆实际前 3 秒及必要的完整开场，记录动作节点、空间状态、相机运动、视听同步与开场结束状态，只保留理解开场及其承接所需的整片上下文，不要求先完成全片深拆。

本次完善仍是内容结构讨论，不表示已经完成真实视频拆解验证或保证高还原复刻。此结果只支持开场范围，不代表具备整片复刻资料。原片拆解保存观察与分析；具体任务另行决定替换元素、适配当前口播与产品、划分生成段及选择制作方式，当前生产的口播不改、不加背景音乐等约束不因新增复刻用途而改变。

- 来源视频资料共用；本 JSON 只引用来源视频标识，不重复保存标题、原始链接、类目、媒体文件、时长与分周期投放数据。引用由程序关联，不让拆解模型编造。
- 开场结果独立保存和检索，不依赖整片拆解存在。同一来源视频已有整片拆解时，可利用其镜头和视听证据补齐本格式，不要求重新完整分析。
- 下面保留中文键名以便讨论。空字符串、数字 `0` 和示例标识只是结构占位，数组中展示一项的形状，不是实际拆解结果。不存在的列表项用 `[]`，无法确认的内容不补造，并在“不确定项”注明。
- 时间统一为相对原视频开头的秒数，可含小数，不从裁剪片段重新计时。实际前 3 秒范围是 `0～min(3, 原视频时长)`；开场镜头若跨过第 3 秒，不人为切成两个镜头，而是通过时间范围读取前三秒实际发生的内容。
- 完整开场可短于或长于 3 秒；开场镜头与视听记录覆盖实际前三秒及完整开场的必要范围。不能将来源数据中一整句“前3秒台词”未经核对就全部计入前三秒。

## 3. 内容填写口径

| 部分 | 内容边界 |
|---|---|
| 已观察范围 | 分别记录开场及为核对承接而查看的后文区间，注明动态画面、抽帧、音频、文字中实际核对了哪些。未查看的中间部分不算已观察 |
| 开场范围 | 分开标记实际前三秒与完整开场；完整开场结束依据可以是悬念提出完成、第一轮动作结束或转入内容展开。原片过短按实际时长；只有截取片段而无法确认开场结束时，结束秒为 `null` 并注明，不自行补成三秒 |
| 必要的整片上下文 | 只概括主题、产品与开场面向的情境，不要求全片阶段或转化分析。没有完整原片时，未知的主题或后文信息不能根据标题补造 |
| 人物场景与产品关系 | 只记录理解开场所需的实体与关系；稳定外观记在实体中，位置、朝向、持物和接触变化记在镜头状态中，不依赖整片实体目录 |
| 开场镜头列表 | 记录主体空间关系、起止状态、带时间的动作节点、相机运动及光色。主体动作与相机运动分开，保留起止构图与连续性；静止镜头不虚构动作，不猜器材参数 |
| 开场视听时序 | 保留台词原文、语气停顿、关键字句时间、声音节奏、包装布局与变化；同步点明确哪个词、动作、声音、文字或切镜在什么时刻配合，不只写“快节奏开场” |
| 吸引机制 | 前三秒表现从实际记录归纳；完整开场解释兴趣如何形成。用关联标识指回镜头与视听依据，不再复制一份前三秒镜头表，不声称已证明播放率或转化效果 |
| 后文承接 | 分开记录开场边界当时的画面/动作/声音状态、紧接后文怎样衔接，以及观看期待在后文哪里兑现。“已核对有承接”“已核对无承接”“未核对”指期待兑现的核对状态，不是动作连续性的状态 |
| 开场参考用法 | 记录适合什么口播开头及后文、依赖哪些台词/音乐/文字/身份，以及不改当前口播时的迁移边界；不提前断言某个未提供的新任务一定适合 |
| 复刻依据 | 说明建议保留的表现关系、替换实体必须满足的操作/形态等条件，以及真实素材或参考素材依赖。只针对开场，不输出新任务模型、调用次数、生成段或最终提示词 |
| 不确定项 | 记录片段缺失、听不清、遮挡、时序不准等，说明对参考或复刻的影响及需补证据。只有三秒片段时，不得把后文“未核对”改成“已核对无承接” |

## 4. 开场复刻的时间与证据规则

1. **前三秒是观察窗口，不是人为切镜。** 跨过第 3 秒的镜头保留真实镜头范围；用动作节点、关键字句时间和同步点确定前三秒内发生什么。若一句口播跨过第 3 秒，保留原文记录，按证据标出关键片段，不把整句都算进前三秒；无法准确区分时标记不确定，不伪造逐字时间戳。
2. **完整开场边界与镜头结束可能不同。** 记录覆盖完整开场及实际前三秒所需的镜头；若边界落在一个长镜头中，可以保留镜头真实范围，只深入分析所需区间，未检查的延伸部分必须说明。不能把裁剪边界冒充原片切点，也不能要求原稿或动作正好在三秒结束。
3. **明确交给后文的状态。** “开场结束状态”的时刻对应已确认的完整开场结束，人物产品与构图、延续中的动作和声音可据此适配新视频后文。它不一定等于最后一个镜头的结束状态。仅看到前三秒且完整开场结束未知时，不填造该状态；等待原片补齐。
4. **后文证据独立定位。** 后文片段通过来源视频标识与时间范围读取，不要求存在整片拆解，也不为一次承接核对建立完整后文镜头表。只有已观察的后文才能支持承接结论；仅核对局部且尚未找到兑现时仍为“未核对”。
5. **镜头、动作、视听和媒体字段与整片共用含义。** 时间统一相对原片，动作与相机运动按所在镜头定位，轨道允许跨镜头。归一化区域使用原画幅左上角为原点的 0～1 坐标，仅表示初始可见布局；移动写在变化过程中。未知数值或布尔值为 `null`，静态关键帧不代替动态片段；完整说明见[整片时间、证据与引用规则](优质视频拆解JSON.md#4-时间证据与引用规则)。
6. **引用仅要求本份结果自洽。** 人物、场景、产品、镜头、动作、视听标识在本份结果内唯一并可解析；没有整片拆解也能独立保存。已存在整片底稿时可复用标识和媒体证据，但两种结果不因同名标识自动同步修改。关键帧媒体引用由程序关联，未提取为 `null`；不让模型编造链接。

## 5. 参考与复刻的使用边界

- **一份开场底稿，按用途读取。** 检索读取开场摘要与适用条件；创意读取吸引机制与可借鉴点；分镜/开场复刻读取镜头、动作、布局、视听同步、开场结束状态与必要后文证据。字段可分阶段补齐，缺什么就注明，不能因为 JSON 有字段就宣称资料已完整。
- **复刻依据不是复刻任务。** 保留动作与镜头关系、替换人物或产品、调整时长等都由具体任务决定；原片秒数用于理解节奏，不是新口播必须塞入的时间窗。新产品必须具备对应功能和操作条件，不能复制原产品的功效、优惠或证言。
- **观察原片与遵守生产规则分开。** 原片的音乐、复杂花字和台词全部照实记录，不能为适配当前能力在拆解阶段删掉。当前不改口播、不加背景音乐、字幕花字后期叠加的规则保持不变，依赖这些元素的方法需要拒绝或明确改编，而非偷偷突破约束。
- **素材复用需要授权。** 原片帧可能含竞品、肖像、字幕或贴片，不默认当成当前任务的干净生成参考。共享来源中的权限及实际授权另行核实，未知授权不推断为可用；素材依赖不是授权结论。

仅开场值得借鉴的来源视频，无须补出整片案例才能保存本结果；但本结果不能作为“已具备整片复刻资料”的依据。
