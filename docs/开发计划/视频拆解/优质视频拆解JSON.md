# 优质视频拆解 JSON（讨论稿）

日期：2026-11-10。状态：结构讨论稿，尚未定稿、实现或入库；不是模型提示词、JSON Schema 或运行时契约。对应的[黄金开场拆解格式](黄金开场拆解JSON.md)独立描述开场参考。

## 1. 用途与边界

面向整片案例，兼顾“参考创作”和“换元素复刻”：既回答这条视频如何表达购买理由，也保留重新组织其画面、动作、节奏与视听配合所需的依据。完整基础镜头时间轴不省略，关键表现按动作节点、空间状态与同步点细化；创意读取摘要与方法，分镜读取相关镜头，复刻读取所需细节。

本次完善仍是内容结构讨论，不表示已经完成真实视频拆解验证或保证高还原复刻。原片拆解保存观察与分析；具体任务另行决定保留什么、替换什么、如何适配当前产品和原稿，以及生成段、模型、提示词和后期方案。

- 来源视频资料共用；本 JSON 只引用来源视频标识，不重复保存标题、原始链接、类目、媒体文件、时长与分周期投放数据。引用由程序关联，不让拆解模型编造。
- 整片与开场的分析结果分别保存；同一视频可以只有其中一种，也可以同时具备。完成拆解不等于已经认定为优质或允许参与检索。
- 下面保留中文键名以便讨论。空字符串、数字 `0` 和示例标识只是结构占位，数组中展示一项的形状，不是实际拆解结果。不存在的列表项用 `[]`，无法确认的内容不补造，并在“不确定项”注明。
- 时间统一为相对原视频开头的秒数，可含小数。实际镜头起止必须按原片填写，不能照抄占位值；口播、声音、包装可跨镜头。

## 3. 内容填写口径

| 部分 | 内容边界 |
|---|---|
| 已观察范围 | 按实际检查过的区间记录，已核对内容区分动态画面、抽帧、音频、文字。只看关键帧不能声称核实了动作过程；未观察部分记入不确定项，不能当成完整拆解 |
| 整片创意与内容结构 | 分析人群情境、需求、购买理由、具体构思与推进方式，不套固定营销公式。视频声称的功效不是已验证产品事实 |
| 人物场景与产品关系 | 同一实体跨镜头使用同一标识；产品本体、包装、配件、其他道具分别识别。这里描述稳定特征，镜头中的持物、位置、朝向变化记录在动作状态中 |
| 主体空间关系与动作过程 | 描述前后左右、遮挡、相对位置及谁接触什么；起止状态记录参与关键动作的实体。动作节点写清原片时间、执行者、作用对象及状态变化，而非只写“展示产品” |
| 镜头表现 | 分开记录主体动作和相机运动，保留起止构图、运动方向、速度变化与停顿。画面速度处理描述可观察的慢动作、倒放、加速等；无法区分相机移动与后期缩放时注明 |
| 光线色彩与材质表现 | 记录可见的光向、阴影、软硬、冷暖、对比和材质细节，不从画面猜精确焦距、灯具型号或布光参数 |
| 与前镜衔接 | 第一镜前镜标识为 `null`、方式为“片头”，无原片过渡区间时起止为 `null`。后续记录切换过程、需保持的持物/位置/光线等状态，以及有意发生的换景、跳剪或时间省略 |
| 关键帧与动态证据 | 关键帧用途区分首帧、关键动作帧、尾帧、布局细节等。帧用于核对静态状态，片段用于核对动作、运镜和节奏，截图不能代替动态证据 |
| 口播对白轨 | 记录实际听到的原文、说话方式及语气停顿。说话人无法关联时为 `null` 并注明原因；关键字句时间只标影响动作或强调时机的片段，不强制逐字标注，不把 OCR 文本直接当台词 |
| 声音轨 | 分开记录动作声、环境声、音乐、音效，描述可听到的节奏与相对音量变化，不猜声音的制作工具、来源版权或精确混音参数 |
| 文字与包装轨 | 区分字幕、花字、标题、贴片、画中画，记录布局、遮挡、样式与出现/退出过程。包装上的字、招牌和界面本身的字属于画面，不直接归为字幕；未知字体不编具体字体名 |
| 视听同步点 | 将动作节点、关键台词、切镜、声音和文字出现关联到原片时刻，例如“杯盖扣合同时出现咔哒声”。记录实际同步关系，不把时间接近自动解释为因果 |
| 关键表达方法与参考用法 | 从镜头与视听记录提炼方法、适用条件和禁止迁移内容；整片摘要供检索，具体方法供创意，选中镜头及证据供分镜，不把全文复制到所有下游 |
| 复刻依据 | 属于可迁移性分析，而非原片事实或任务指令。保留建议说明哪种关系影响表达；替换约束说明新元素需要具备什么条件；素材依赖说明外观参考、真实操作、录屏或证据素材等需求 |
| 不确定项 | 记录缺失、未观察、冲突或无法准确定位之处，以及对参考/复刻的具体影响和补证需求。不能以空列表假装“没有该元素”，也不设置凭空打出的“可复刻评分” |

## 4. 时间、证据与引用规则

1. **统一原片时间。** 镜头、动作节点、相机运动、口播、包装变化、同步点和证据全部使用同一原片时间基准。动作与相机运动位于所属镜头范围内；轨道可跨镜头，字幕不因切镜重复建一条。静止镜头可没有动作节点或相机运动，明确记录固定状态即可。
2. **区分切点与过渡。** 硬切的衔接开始/结束可为同一切点；叠化等记录实际过渡区间，不额外制造一个镜头或生成段。过渡可能覆盖相邻镜头边缘，不能把镜头与过渡时长相加来重建总时长。
3. **不制造精度。** 位置文字描述是基础；需要复刻包装布局且能确认时，补归一化区域，原点为画面左上角，x/y/width/height 为相对原片画幅的 0～1 数值。位置变化写在变化过程中，该区域仅作为初始可见布局，不代表完整运动轨迹。数值或布尔判断未知用 `null`，不得填 `0` 或 `false` 冒充测量结果；时间估计与边界不清写入不确定项。
4. **区分未见与不存在。** `[]` 表示已观察范围内没有相应记录或不适用；如果未检查该维度，必须同时说明未观察范围及不确定项。“已观察范围”不由视频文件存在与否推断。
5. **保留可回看的证据。** 动态片段由来源视频标识与起止时间定位，不必重复裁出文件。关键帧媒体引用复用共享媒体能力，由程序关联；还未提取时引用为 `null`，不让模型编造 URL 或素材 ID。关键帧必须标明原片时刻和用途。
6. **引用可解析。** 阶段、镜头、实体、动作和视听记录使用各自唯一标识；引用应指向本份结果中的真实记录，不以自由描述代替标识。现有示例标识仅为占位，不是数据库 ID。具体媒体引用结构与最终类型约束留待正式契约。

## 5. 原片拆解与复刻方案的分界

- **原片拆解保存依据，不替本次任务决策。** 这里不写目标产品、替换后人物、具体模型、调用次数、生成段、最终提示词或改编后时间轴。镜头数量不是生成次数；新任务根据配音、动作和模型能力重新分段、排时序。
- **可替换不等于任意替换。** 复刻依据应说明操作、尺寸、握持、接触、材质变化等条件；从榨汁杯换成保温杯时不能沿用搅拌动作。原片中的功效、优惠、测试或证言不能成为新产品事实，真实证据不得用生成画面冒充。
- **素材可看不等于可用。** 原视频、人物肖像、音乐、字体和贴片的复用权限由来源资料及实际授权核实，不让拆解模型判定授权成立。复刻需准备当前任务有权使用的素材；原片帧如含字幕/贴片，不能默认直接作为干净生成参考。
- **不同用途读取不同深度。** 创意读摘要与表达方法；分镜读被采用镜头的动作、构图和同步关系；复刻读相关实体、完整时序、连续性、素材依赖及证据。未补齐关键动作/声音等信息的案例仍可用于有依据的参考，但不能因此声称已具备高还原复刻资料。
- **原片音乐照实记录，当前生产规则不变。** 分析可写明依赖音乐、复杂包装或特定台词；在不改口播、不加背景音乐及既定字幕花字方案下，无法成立的方法应被拒绝或明确改编，不能借复刻用途暗中扩大现有能力。

整片中的开场方法可作为独立黄金开场拆解的底稿，但不在本 JSON 内再嵌入一份完整的黄金开场结果。按[黄金开场拆解格式](黄金开场拆解JSON.md)提取和补齐所需细节，两份结果共用来源，不因同名标识自动同步修改。
